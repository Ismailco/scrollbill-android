The weekly loop

Useful before it is shareable.

ScrollBill keeps the useful part simple: understand the last seven completed days, then decide if you want to share the receipt.

01

Grant Usage Access

Android shows you exactly which special access ScrollBill needs. You can revoke it at any time in system settings.

02

Understand the week

See total app time, a daily average, yearly pace, and the applications that took the most foreground time.

03

Make a receipt

Turn the current seven-day report into a 1080×1920 PNG and share it only when you choose a destination.
