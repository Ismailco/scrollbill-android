# ScrollBill store assets

These assets are the supplied ScrollBill generated artwork for the `0.1.0` listing. They are promotional references and contain illustrative sample values; they are not a user's device history.

- `app-icon-512.png`: full-color Play app icon derived from the supplied approved icon.
- `feature-graphic-1024x500.png`: horizontal Play feature graphic.
- `screenshot-weekly-overview.png`: weekly summary promotional image.
- `screenshot-receipt.png`: receipt promotional image.
- `screenshot-insights.png`: insights promotional image.
- `screenshot-share.png`: sharing promotional image.
- `scrollbill-wordmark.png`: supplied transparent wordmark source.
